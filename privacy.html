DJGuita publishing — Privacy Policy

Effective November 24, 2026. Yukiyu Records LLC, the publishing house of the artist DJGuita.

What this application is

"DJGuita publishing" is a private tool run by Yukiyu Records LLC for one artist, DJGuita. It publishes the artist's own videos to the artist's own YouTube channel and keeps the artist's own playlists in order. It is not offered to the public and has no users other than the artist and the people who work for her label.

What it accesses

With the channel owner's consent through Google's sign-in, the application uses the YouTube Data API to upload videos to that channel, set their titles, descriptions, tags and privacy, and add them to the channel's playlists. It reads only the channel's own information needed to do that (for example the channel's title and its playlists).

What it stores

It stores the authorization token Google issues at consent, on a computer operated by the label, so the channel owner does not have to sign in again for every upload. It stores no information about any other person, no viewer data, no comments and no subscriber data.

What it shares

Nothing. The application does not sell, rent, share or transfer any Google user data to anyone. It does not use Google user data for advertising, profiling or any purpose other than publishing the artist's own videos to the artist's own channel.

Google's policies

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The channel owner can revoke the application's access at any time at myaccount.google.com/permissions. Revoking it stops every upload at once; nothing else changes.
